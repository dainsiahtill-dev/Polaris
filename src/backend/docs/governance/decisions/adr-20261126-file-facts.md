# 文件事实按工程事件顺序派生

`roles.runtime` 在准备请求时，根据当前运行中成功的 `read_file` 观察生成有界的路径摘要。快照存储按内容寻址；同一内容可以属于多个路径。读权限和路径归属在取回时由宿主核对。

工程验证结果只在该候选的验证事件及源码清单能绑定文件版本时才出现在摘要中。最近观察的旧版本仍可按地址取回。内容恢复和 QA 的当前候选取证分别保留自己的回执。

请求编译、manifest 和工作台因此可以沿同一条来源核查版本、证据地址和捕获角色。决策与复测入口见[实施蓝图](../../../../../docs/blueprints/CONTEXT_FACT_CONVERGENCE_20261126.md)。
