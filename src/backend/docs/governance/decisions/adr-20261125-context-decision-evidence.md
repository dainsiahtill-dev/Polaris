# 以同一证据边界编排每轮上下文

状态为选定设计，按迁移阶段独立验证。owner 为 roles.runtime。

## 决定

由现有 engineering loop 把宿主运行事实、当前角色可用的证据和三兽建议组装为每轮请求。辅助建议必须按其输入快照、观察区间和消费角色绑定。模型解释不能裁决文件是否写入、命令是否通过或候选是否被独立接受。原始事实和恢复位置仍由现有 workspace journal 与 ContextOS 快照提供。

## 理由与代价

真实 L1-01 出现 exit 0 被当成持续失败、吞噬兽从单轮推断十轮、QA 收到交接给自己的指令。分别调节三个模型的提示词不能修正宿主对证据的选择。统一投影增加宿主校验与预算分配工作，换取可重放的局部选择和一条可核实的物理请求路径。可读记录照旧保留，历史无绑定的推断只能作为历史资料。
