# ADR: settle repair continues the original Director authority

Accepted under approved unattended master plan; original authority locally
verified, automatic cross-owner continuation in implementation; fresh proof pending.

Typed plan paths must not mint write permissions. Factory stage settlement uses
the existing canonical owner claim, strict CE handoff, original capability and
completion projection. No synthetic CE fallback or helper-project ownership.
Use existing public Director tasking/DEO and execution_broker asset APIs; register
effects before successful TaskRuntime close. Canonical verifier/boundary facts
remain the only completion authority. Local tests are not fresh qualification.

Cost: previously accepted unowned derived-file repairs now reject and require a
repair of an already-owned manifest/config or an explicit contract amendment.
This is intentional: creating an arbitrary file to satisfy a metric cannot prove
the authored project completed. Ordinary owner-local code edits remain automated.
