# PM planning validation precedes execution ownership

Status: implemented with component verification; native delivery pending.

Factory consumed the admitted semantic PM intent through two legacy assumptions: scope/steps were mandatory and missing execution_backend implied an immediate code-edit artifact promise. Both assumptions belong to execution preparation rather than product planning.

Use the existing PM public semantic contract and canonical projection to qualify deferred technical declarations in an explicitly selected planning phase. The artifact validator remains strict by default and all declared technical constraints continue through its existing gates. CE signed handoff and Director capability guards remain execution authorities. Factory selects planning validation before CE handoff. After CE handoff, materialization validation derives required owned artifacts from the strict same-run public CE task completion projection and its immutable JobToken; legacy execution validation remains strict.
