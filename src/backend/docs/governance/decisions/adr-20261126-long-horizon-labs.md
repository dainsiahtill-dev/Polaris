# 工程研究计划与角色工作流独立配置

显式研究计划为一次工程运行指定实验室与版本依赖。计划作为用户提交的研究输入持久化；EngineeringRunService 继续拥有 admission、恢复、实际验证和 QA。依据同一 workspace 中宿主允许读到的资料，按选中实验室的依赖闭包生成有界观察。研究材料和模型输出均无授权与验收权限。失效或缺失记录进入同一运行的证据反馈。

项目级汇总读取原工程 SQLite，不派生第二个调度器或实验进度账本。原始资料、论文与报告储存在被研究项目中，由明确版本引用定位。细节见[实施蓝图](../../../../../docs/blueprints/LONG_HORIZON_RESEARCH_EVIDENCE_20261126.md)。
