# Initial Audit Remediation Blueprint 2026-06-19

## Goal

Close the first audit's cross-surface regressions before resuming broad
factory_bench work. The fixes must keep existing Cell boundaries intact and
produce fresh verification evidence instead of relying on "resolved" status.

## Scope

- Frontend runtime hook: prevent stale WebSocket reconnect state from ignoring
  finite retry limits.
- HTTP delivery workspace helpers: compare workspace paths using path-sensitive
  case semantics instead of treating all WSL paths as case-insensitive.
- Roles kernel LLM events: keep full response content on call-end metadata when
  required, but emit only bounded preview payloads for content-preview events.
- ContextOS modal: remove invalid nested interactive controls while preserving
  expand/copy behavior and focus handling.
- Factory QA gate: default to requiring LLM judgement unless explicitly disabled.
- Tests: remove async warning noise and add regression coverage for the above.
- Repository hygiene: identify runtime artifacts generated by live services.

## Architecture Notes

```text
Frontend UI
  useWebSocketWithFallback -> WebSocket lifecycle state
  ContextViewerModal       -> read-only ContextOS inspection

Backend delivery
  workspace.py             -> advisory ACL comparison helpers

Roles kernel
  LLMEventEmitter          -> canonical lifecycle events

Factory pipeline
  quality_gate             -> deterministic evidence + LLM judgement policy
```

No new Cell is introduced. Backend changes stay in existing delivery,
roles.kernel, and factory pipeline ownership areas. Generated runtime state is
not treated as source truth.

## Verification Plan

- Frontend: focused Vitest for WebSocket hook, ContextViewerModal, and selectors.
- Frontend: `npm run typecheck`.
- Backend: focused pytest for workspace, context store, LLM caller components,
  and factory run service.
- Backend: `ruff check --fix`, `ruff format`, and `mypy` for touched Python
  files.
- Repository: `git diff --check` and final dirty-state audit.
