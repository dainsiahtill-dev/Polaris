# 弱模型放大的理论基座：哪些定理真正承重

日期: 2026-06-13 ｜ 性质: 理论综合（五透镜并行推导 + 对抗性严谨审查）
实证锚点: `I3_MARKET_FISSION_QUANT_REPORT_20260613.md`（r1–r13 十二修活体数据）
方法: 5 个独立理论透镜（信息论/控制论/计算学习论/组合正确性/信息瓶颈）各自给出

## 0. 命题的理论形态

「让弱模型做出顶级水平」在理论上**不是**「让弱模型变强」。所有存活的定理说的是同一件事：

> 在 **验证可机器化、任务可分解、接口可契约化** 的域内，弱执行器的不可靠性
> 可以被架构吸收到任意低——代价是墙钟与每域一次的契约工程。

这正是 von Neumann (1956) "Probabilistic Logics and the Synthesis of Reliable
Organisms from Unreliable Components" 的现代复刻：从 ε-错误元件构造任意可靠系统，
靠的是冗余 + 表决（这里：重试 + 机器裁决），不是元件变好。
天花板钉在两处：**验证不可机器化处**（审美/语义正确性）与**单步不可再分处**。

## 1. 七条设计法则（经对抗审查存活的承重结论）

### 法则 1（裁决律）— 系统可入账的可靠性 ≤ 验证器健全性
三个互不相识的形式体系推出同一恒等式：Recovery blocks 的验收测试逃逸上界
（Randell 1975）、检错码漏检概率 P_ud（ARQ 残余错误由检测器而非重传预算决定）、
von Neumann 的末端器官下界。**全卷唯一无保留存活的 tight 映射。**
活体显形：r9 的「任何变更即过」证据门 = 0 校验比特的检错码 → 假阳性 resolved；
修复后账面 4/7→诚实 0/9→r12 3/8 零假阳性。先修计分板，数字必然先跌，然后才有真增益。
推论：一切 best-of-N / 采样类方案的**前置条件**是验证器健全——否则采样压力变成
对验证缝隙的优化搜索（APR 文献的 test-suite overfitting，过拟合补丁占比可超 50%）。

### 法则 2（预防律）— 可语法化的故障类应预防，而非容错
logit mask 对支撑集的裁剪使 P(非法输出) ≡ 0——这是集合论事实（token 级
Ramadge–Wonham 监督控制，Σ_u=∅ 特例），不需要更重的定理背书。实证两次归零：
schema 收窄使散文逃逸数十→0；enum 钉靶封死写错文件类。
资源分配裁决：故障类从「容错域」（每次激活 ~16min 市场重试）迁入「预防域」
（一次性成本、首试生效），prompt 文本投入在这些故障类上期望收益 ≈ 0。
可审计预测（水床效应）：被 mask 通道归零后，错误质量向未监督通道
（execute_command 副作用、edit_blocks 内嵌 filepath）迁移——触碰溯源直方图可验。

### 法则 3（反馈律）— 反馈不提升能力上限，但把达到给定可靠度的时间压缩数量级
Shannon 1956：反馈不增加 DMC 容量——再快的 verify 反馈也没让 27B 变聪明
（能力型失败反馈救不了）。但 Burnashev 1976 / Schalkwijk–Kailath 1966：
反馈摧毁性地改善误差指数与时延。串级控制同款结论：内环必须比外环快 5–10×。
活体显形：市场反弹环 RTT ~30min/圈、每圈一次盲猜（r10/r11 死亡螺旋）；
Fix-9 把 verify 移入执行轮（秒级内环）后，r12 全部 resolved 步**首试一次过**，
r13 创建模式四连首试直达 QA。停等吞吐公式 η ∝ T_f/(T_f+RTT) 同时解释 6× 墙钟。

### 法则 4（信息律）— 重试的价值 = 每轮携带的新信息；教学比特数决定收敛轮数
有记忆信道上纯重复重传（Chase 合并）对确定性偏置增益 ≈ 0，只有增量冗余
（HARQ-IR，每轮新信息）有效。Knight–Leveson 1986 同款：同源重试失败强相关。
活体显形：r12 首试成功率 p₁=0.6，若重试独立应救回 ~2.4 步，实测 0/4
（二项检验 p≈0.026）——零 diff 重写、camelCase 习惯复现是相关系数=1 的极限。
教学信息量分层：泛化「failed」≈0 bit；点名第 k/n 子句 = log₂n bit（Fix-10）；
回传「实测 vs 要求」残差（行数差、命中数差）≈ 6–8 bit（待实现 T2）。
辨识熵下界：反馈不携带 log₂n bit 时接收方只能盲猜，期望轮数 O(n) 而非 O(log n)。
r12 1-S2 之死是字面意义上缺 3 bit 的死亡（7/8 子句过，不知道要删 38 行）。

### 法则 5（降率律）— 超容量步唯有再裂变，重试与教学都救不了
噪声信道编码定理的逆定理（R > C 时错误概率有正下界）的工程化（操作性代理，
非可测香农容量）：存在「单步内容熵超过弱模型单次可靠生成预算」的步类，
对它们加大重试预算 N、再增教学比特都推不过阈值，唯一出口是降码率——
步一拆二、签名细化。分块数学：每行错误率 ε 下整块干净概率 (1−ε)^L 指数衰减，
串行 387 行单块从未干净、裂变 ≤120 行逐块校验后复合产物干净——
「智能上移、执行下沉」= 编码设计上移到高容量节点、弱链路只承载低于单次容量的载荷。
结构缺口：当前 DLQ 是终点站，没有「降率出口」（pending_ce_revision 通道，见 §4）。

### 法则 6（组合律）— 局部校验之和 ≠ 全局正确；接口义务必须机器化 discharge
Assume-Guarantee 组合验证：每步满足契约 ⇒ 组合满足规格，**前提是接口契约相容**。
乘积码视角：单文件 verify = 行校验，跨文件标识符一致性 = 缺失的列校验——
「所有行校验通过但矩阵错」是预期事件而非意外。
活体显形：接口定名漂移（合同 `id="game-canvas"` vs 模型习惯 `gameCanvas`），
单文件 grep 子串撞运气可过、跨文件组合断裂。三透镜独立收敛到同一构件形态：
interface_names 从提示文本升级为机器义务表 + 双侧锚定 verify 子句 + DAG 尾部集成验证步。

### 法则 7（经济律）— 下一个 16 分钟花在哪是最优停止问题，不是固定预算问题
批判员点名的四透镜集体盲区：重试-升级-弃置是带显式成本的序贯决策
（本地重试 16min vs 云升级 $ vs 再裂变 vs 弃置），Gittins 指数 / Wald SPRT
给出有原则的裁决机器，替代 ad hoc 的「3 次盲烧」。6× 墙钟的支配项是**排队结构**
（单 worker 串行轮询、QA 外环 RTT、失败步重试）而非信息内容——排队论 + DAG
关键路径调度是当下边际收益最大的可计算问题（E1 worker 池设计已有、未兑现）。
方法论纪律：每跑 8 步的检验功效近乎零，20+ 个 A/B 提案必须合并为少数预登记
旗舰假设 + 配对 runner，否则多重比较下期望假阳性 ≥ 1。

## 2. 计算与学习理论透镜（补编）

- **生成-验证不对称（NP 结构）**：verify 谓词 = 多项式时间验证器。整个架构
  是该不对称的工程开采：弱生成器 + 廉价健全验证器 + 重试 = **把 Monte Carlo
  生成器包装成带证书的 Las Vegas 过程**（期望尝试数 1/p，交付必带证书）。
  前提恰是法则 1 的健全性。Levin 通用搜索是该范式的理论极限（带验证的枚举
  最优到常数因子）——市场是它的实用化退火版。
- **Boosting 定理（Schapire 1990）的诚实裁决**：「弱可学习 = 强可学习」是本命题
  在 PAC 框架的字面亲属，但其前提在此**失效**——权重冻结无分布重加权、
  无「任意分布上弱优势」保证。反弹教学≠AdaBoost 重采样（模型不更新）。
  借 boosting 之名宣传本系统是装饰；真正的亲属是 **pass@k 收割**：
  LLM 实证 pass@k 随 k 增长远快于 pass@1，verify 让我们以 pass@1 的交付
  形态收割 pass@k 的成功率——1−(1−p)^N 仅在采样多样性足够时成立（法则 4
  的相关失败警告同时适用：同温度同 prompt 的 N 路不是独立试验）。
- **APR 过拟合定律（Qi 2015 / Smith 2015）**：plausible-but-incorrect patch
  有十年实测——这给 best-of-N 的风险定了先例数字，并把「verify 子串撞运气」
  从轶事升格为已命名的系统性风险类。

## 3. 被降级的美丽类比（诚实记录，防止未来引用通胀）

| 类比 | 降级裁决 |
|---|---|
| guided decoding ↔ RLL 受限编码定理 | 降 structural：承重的只是「支撑集裁剪 ⇒ P(非法)=0」平凡内核；容量公式 C=log λ(A)、state-splitting 编码器全程未用。且 mask+重归一化 ≠ 真条件化，约束集内分布质量无定理保障 |
| DPI ↔ 接口定名漂移 | 降 structural：DPI 是系综互信息命题，对单条 prompt 不产生定量结论；「字面量不在 T 中 ⇒ 概率被封死」不是 DPI |
| End-to-end argument ↔ QA 终审 | 降 structural：SRC 1984 是设计论证非定理，且「端点」在本系统三层歧义（步级/组合/用户意图） |
| 信源信道分离 ↔ 三层架构 | loose：分离定理前提（平稳遍历）不成立；组织学价值仅在「冗余必须由高容量节点预付」 |
| Vygotsky ZPD / 脚手架 | 主体 loose：系统无学习，脚手架是**永久假肢**——唯一存活的是否定性结论：fading 类优化无理论依据 |
| est_lines ≤ 120 ↔ K(y) 上界 | loose：行数界住字面长度，不是条件复杂度 K(产物\|契约)——价值纯在自我批判，指出真正该测的量 |
| 机制设计 ↔ 任务市场 | 不承重：无策略代理、无私有信息，claim/lease 是工作队列不是拍卖 |
| 「verify 确定性 = 零错误容量体制」 | 删除：C₀F>C₀ 是信道混淆图性质，与接收端判决规则不是同一对象 |

## 4. 工程预测排名（影响/成本，批判员裁定）

1. **接口义务表 + 双侧锚定 verify 子句 + 集成验证步**（四路收敛）：interface_names
   编译为机器谓词（声明侧/使用侧 grep 双侧出现性），DAG 尾部加集成步；
   纯确定性工具链零新模型调用。先跑零成本回放：对 r9–r13 历史工件做悬空引用审计。
2. **教学载荷升级 T2 残差量化**：wc -l 回传行数差、grep 回传命中数差、test -f
   回传实际文件清单——全是解析级提取，挂在 Fix-10 子句通道上；预期把可量化
   子句的多轮反弹压成单轮（每省一轮 = 省 ~16–30min）。
3. **空验收 pre-state 自检门**：CE 门在「依赖就绪、本步未做」快照上跑 verify，
   exit 0 ⇒ 空验收 ⇒ corrective re-ask。保护法则 1 的计分板，是 best-of-N 的安全前置。
4. **信息门控重试 + 多样性阶梯 + 领取快照回滚**：教学载荷哈希比对，零新信息
   跳过剩余预算直接升级；attempt-3 强制换执行形态、attempt-4 单次云备选
   （Randell 备选块本义：相异设计而非同设计重跑）；重试前回滚 target_file 消灭
   「文件看似完成→零 diff→EXEC_NO_EVIDENCE」共因（已三次实证）。
5. **契约修订通道 pending_ce_revision**：补全责任三角缺边——执行方违约有 requeue、
   依赖失败有级联，契约作者违约无路由；尽力判据（diff + 子句通过率）数据已全在
   transitions。同时是法则 5 的降率出口：DLQ 不再是终点站。

另三个零成本回放审计（用既有数据裁决前提，不烧新跑）：历史工件悬空引用、
pre-state 空验收扫描、「字面量在场 vs 子句通过」分层统计（验证充分核假设）。

后续大项（法则 7）：worker 池并发 + 关键路径优先 claim（6× 墙钟的结构项）；
SPRT 化的「超容量步」判定（替代『跨 ≥2 跑根因死信』的拍脑袋判据）。

## 5. 统一图景

系统可入账产出率的结构分解（序关系，非可拟合公式）：

```
可入账成功率 ≈ 健全验证器覆盖率            ← 法则1（地板与天花板）
            × Π(1 − 未预防故障类激活率)     ← 法则2（语法预防）
            × σ(每轮反馈信息 / 缺失熵)      ← 法则3+4（反馈率与教学比特）
            × [步码率 < 单步容量]           ← 法则5（裂变粒度，0/1 门）
            × 接口义务 discharge 率          ← 法则6（组合粘合）
墙钟      ≈ 排队结构项（RTT×反弹轮数 + 串行轮询） ← 法则3+7
```

十二修的每一修都落在其中一项上；r12 两类根因死亡（教学盲 = 法则 4 violation、
预算硬炸 = 反馈通道自身被截断）与残余接口漂移（法则 6）在该图景中全部有座位。
这不是事后贴标签的检验：**法则 4 在 r12 数据上做出了与直觉相反的定量预测**
（重试预算几乎不贡献可靠性，p≈0.026 拒绝独立性），并直接改写了重试策略设计空间。
