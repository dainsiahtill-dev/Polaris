# PM、CE、Director 组合：有限质量预试验

状态：已预注册的实验方案。执行前冻结源码；实际启动、所有尝试与结果记录在外部实验目录。以下是固定实验设计，不是能力结论。

## 要回答的问题

固定总预算、任务、模型、权限及质量要求，比较五种咨询策略，哪种更容易交付**正确且丰富**的成品：Director 自规划；PM 后 Director；CE 后 Director；PM、CE 后 Director；Director 按需咨询。

当前 e700 的 L1-01、L1-02、L1-03 都有平台 accepted 和原资源关闭，亲自验收均失败：时钟单位、历史提醒日期、逐帧入口分别存在核心缺陷。这三例是不同任务的探索观察，不能证明缺文档或缺某角色是原因。

## 实验单位与共同条件

原目录 L1-02「梦境便签炼金炉」及 L1-03「迷你行星天气球」，每组每任务一次，共10次。使用全新 workspace、独立实例和原工程 owner；一次结束、资源关闭、主 Agent 亲自检查后才开始下一次。不修改原目录，不外部代修或安装目标依赖，不写原生验收证据。

原 `build_requirements_doc(original)` 完整保留；在外部冻结输入中另行标明统一用户质量澄清和唯一组别指令。保留全部业务、数值深度、真实入口、依赖、构建和检查要求；旧合同记账术语按新工程兼容说明解释，不恢复旧准入。

所有组都由 Director 在产品源码写入前，先生成可读 `docs/PLAN.md`、`docs/DESIGN.md`，说明用户旅程、完整范围、创意机制、状态和时间单位、关键设计与验证。PM/CE 只读建议，Director 综合落盘。文档是工作材料，篇幅和数量不加分。这样可以研究专家贡献，避免把“有无事先设计”混进角色效果。

五组统一使用已有 `direct` 正式入口和同一 `consult_role` 能力，避免只有全链组使用 `collaborative` 带来的入口混淆。固定组由 Director 在编码前实际串行咨询指定专家；PM、CE 各一次，全链将真实 PM 建议带入 CE 问题；自规划组不咨询；按需组自行选择。实际调用依从性用持久事件、工具观察和最终请求核验。违例仍按分配组计入，不挑最好样本，也不把指令当作已执行。

当前模型、host、工具和权限完全一致；所有角色、实现、验证、修复、独立 QA 共用5400秒，总守护6000秒。咨询开销计入，不给每个角色重置预算。该比较估计固定预算下的策略效果，不能单独分离角色身份和额外计算贡献。

## 固定顺序与有限终点

按任务分块，块内随机，seed=20261021。精确顺序：

1. L1-02：PM/CE、CE、PM、自规划、按需。
2. L1-03：自规划、按需、PM/CE、PM、CE。

正常失败且安全关闭，继续预先分配的下一例；未知效果或资源归属未收口，先封存并停队列。确需通用源码修复时另起版本，不把旧样本混入同一冻结批次。

10次后，仅有过一次“正确且丰富”成功的组可入围；不足两组，停止选优推断，报告证据不足。满足条件才追加最多8次：两个入围组、两个原任务、各两个全新重复，seed=20261022。复制数据和筛选数据分别报告。小样本只支持限定策略选择，不能宣称全部 L1–L12 的普适最优。

## 如何检查质量

先正确性：当前原生验证、独立 QA 和项目接受成立；主 Agent 真正运行主入口与核心旅程；无已发现 P0/P1 核心错误。未实际检查记 UNVERIFIED。漂亮界面不能抵消错误业务。

再评五个方面，各0–4分：旅程闭环、创意钩子、领域深度、边界与恢复、界面反馈与可理解性。丰富要求各项至少2、旅程和创意各至少3、总分至少14/20。这是预先固定的工程判断口径，尚非经验证的通用量表。文件、行数、测试数、文档篇幅和按钮数均不计分。

L1-02 检查便签创建与修改、输入影响合成、来源、保存后重入，以及到期前/边界/后/取消提醒；L1-03 检查真实帧、云/风/昼夜各自效果、参数修改、暂停继续与重置、seed 和时间单位。Web、TUI、桌面或 CLI 按真实入口验证，不因语言强加 HTML。不能只测未接入实际路径的 helper。

原实例先关闭，主 Agent 再对同一不可变候选执行只读辅助沙箱/浏览器质量检查，每例上限1200秒；辅助资源和审查时间另记，关闭后才进入下一例。外部审查不冒充 native verifier，也不回写平台 accepted。初评尽量不读角色日志与设计材料，但主 Agent 负责调度，无法完全盲法，且只有一名评审者。

同时记录所有启动、失败、超时、取消、实际链、首次有效代码时间、真实工具效果、实际验证、恢复、资源、审查时间和总尝试成本。物理 HTTP 次数和账单未知保持 UNKNOWN；快照数不能替代。通过率以全部分配/已尝试样本分别列分母，不隐藏启动失败。
