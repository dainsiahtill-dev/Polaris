# PM semantic intent at Factory admission

Factory validates semantic product obligations before Chief Engineer design. PM does not need to invent artifact paths, steps, or verification recipes. The public PM artifact validator accepts an explicit `pm_planning` validation phase, revalidates the existing semantic contract, and verifies its canonical projected declarations. Only a fully canonical semantic projection can defer empty code-edit ownership; explicit paths, commands, generated outputs, dependency graphs, and collisions retain their existing checks.

Flow: PM public intent admission; Factory pre-CE semantic/artifact revalidation; CE public portfolio and signed handoff; Director envelope and Job Token scoped tools; TaskBoundary and QA evidence. The validator defaults to strict execution validation. Legacy tasks retain scope/steps and useful-owned-artifact requirements. Planning phase is never an execution permission. Post-CE ownership and genuine verification-only handoff checks stay in their existing Cells.

Risk: metadata-only recognition, stale aliases, or a forged execution backend could bypass a simple conditional. Canonical round-trip checks reject these. No generated target project code is modified; source component acceptance cannot prove native delivery.
